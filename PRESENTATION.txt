================================================================================
                    AI SOCIAL MEDIA AGENCY - PROJECT PRESENTATION
================================================================================

                              PROJECT OVERVIEW
--------------------------------------------------------------------------------

The AI Social Media Agency is a comprehensive platform that leverages artificial
intelligence to help brands manage, create, and optimize their social media 
presence. It combines multiple AI agents that work together to analyze brands,
generate content, manage campaigns, and provide actionable recommendations.

The system is built with a modern tech stack: Next.js 16 for the frontend and 
FastAPI (Python) for the backend, with Google Gemini 2.5 Flash as the AI engine.


================================================================================
                              CORE FEATURES
================================================================================


1. BRAND MANAGEMENT & ANALYSIS
--------------------------------------------------------------------------------

   What it does:
   - Allows users to add brands by providing an Instagram handle
   - Automatically scrapes and analyzes the Instagram profile
   - Extracts brand voice, target audience, content themes, and posting patterns
   
   How it works:
   1. User enters brand name and Instagram handle
   2. Backend uses Instaloader to scrape recent Instagram posts
   3. AI (Gemini) analyzes the content to understand brand personality
   4. Results are stored and displayed as a "Brand Profile"
   
   Technical flow:
   POST /brands/ → Creates brand → Triggers Instagram scraping → AI analysis
   GET /brands/{id} → Returns brand with profile data

   Key files:
   - backend/agents/brand_analyzer.py - AI analysis logic
   - backend/scraping/insta_scraper.py - Instagram data extraction
   - frontend/app/page.tsx - Brand dashboard


2. AI CONTENT GENERATION
--------------------------------------------------------------------------------

   What it does:
   - Generates content ideas based on brand profile
   - Creates platform-optimized captions (Instagram, Twitter, LinkedIn)
   - Suggests relevant hashtags
   - Generates AI images using custom prompts
   
   How it works:
   1. User clicks "Generate Content" on brand page
   2. AI analyzes brand profile and creates 5 content ideas
   3. Each idea includes: title, description, content type, caption hook, hashtags
   4. User can create posts from any idea with one click
   
   Caption Generation:
   - Single platform: Optimized for character limits and style
   - Multi-platform: Simultaneous generation for all platforms
   - Considers brand voice and target audience
   
   Image Generation:
   - Uses Pollinations.ai API for high-quality images
   - User provides title and description
   - AI creates visuals matching the brand style
   - Images can be downloaded directly
   
   Key files:
   - backend/agents/content_agent.py - Content generation logic
   - frontend/app/brand/[id]/create/page.tsx - Content creation UI


3. CAMPAIGN MANAGEMENT
--------------------------------------------------------------------------------

   What it does:
   - Create and track marketing campaigns
   - Link Instagram posts to campaigns
   - Get AI-powered performance analysis
   - Generate comprehensive campaign strategies
   
   How it works:
   
   Creating Campaigns:
   1. User defines name, type (organic/paid/mixed), objectives
   2. Sets platforms, budget, and date range
   3. Campaign is created and tracked
   
   AI Analysis:
   1. Collects campaign metrics (impressions, clicks, conversions)
   2. AI analyzes performance patterns
   3. Provides insights: what's working, what needs improvement
   4. Suggests optimization actions with priority levels
   
   AI Strategy Generation:
   1. Analyzes brand profile and campaign objectives
   2. Creates complete content calendar (7-30 days)
   3. Suggests platform-specific strategies
   4. Defines KPI targets and success criteria
   5. Each calendar item has a "Create" button for instant content creation
   
   Key files:
   - backend/agents/campaign_agent.py - Campaign AI logic
   - frontend/app/brand/[id]/campaigns/page.tsx - Campaign UI


4. AD PLATFORM RECOMMENDATIONS
--------------------------------------------------------------------------------

   What it does:
   - Analyzes brand and campaign objectives
   - Recommends top 3 advertising platforms
   - Provides budget allocation suggestions
   - Shows expected ROI and performance metrics
   
   How it works:
   1. User selects campaign objectives (awareness, leads, sales, etc.)
   2. Sets total budget and target metrics (CTR, conversions, ROAS)
   3. AI analyzes and recommends platforms from:
      - Google Ads (Search, Display, YouTube)
      - Meta Ads (Facebook, Instagram)
      - LinkedIn Ads
      - Twitter/X Ads
      - TikTok Ads
   
   For each platform, AI provides:
   - Confidence score (0-100%)
   - Recommended budget portion
   - Expected ROI
   - Pros and cons
   - Recommended ad types and bidding strategy
   - Expected metrics (impressions, clicks, CTR, CPC)
   
   One-click actions:
   - "Create Content" → Opens content creator with platform context
   - "Create Campaign" → Creates campaign from recommendation
   
   Key files:
   - backend/agents/campaign_agent.py - recommend_ad_platforms()
   - frontend/app/brand/[id]/ad-recommendations/page.tsx


5. COMPETITOR ANALYSIS
--------------------------------------------------------------------------------

   What it does:
   - Analyzes competitor Instagram accounts
   - Compares metrics (followers, engagement rate)
   - Performs SWOT analysis
   - Identifies trending content
   
   How it works:
   1. User adds competitor Instagram handles
   2. System scrapes competitor data
   3. AI performs comparative analysis
   4. Generates:
      - Metrics comparison
      - Strengths & Weaknesses
      - Opportunities & Threats
      - Strategic recommendations
   
   Trending Content Feature:
   - Identifies trending topics in competitors' content
   - Shows top-performing posts with engagement data
   - Provides actionable insights
   
   Key files:
   - backend/main.py - /analyze-competitors endpoint
   - frontend/app/brand/[id]/competitors/page.tsx


6. ANALYTICS DASHBOARD
--------------------------------------------------------------------------------

   What it does:
   - Displays performance metrics over time
   - Shows engagement trends
   - Tracks post performance
   
   How it works:
   - Aggregates data from Instagram and campaigns
   - Visualizes with interactive charts (Recharts)
   - Supports different time ranges (7d, 30d, 90d)
   
   Key files:
   - frontend/app/brand/[id]/analytics/page.tsx


================================================================================
                           AGENT INTERCONNECTIVITY
================================================================================

The AI agents work together, passing context between features:

1. Content Ideas → Create Post
   - Click "Create" on any content idea
   - Opens creator with title, description, hashtags pre-filled

2. Ad Recommendations → Create Post
   - Click "Create Content" on any platform recommendation
   - Opens creator with platform selected
   - Includes ad context (content tips, objectives, budget)

3. Campaign Strategy → Create Post
   - Each content calendar item has "Create" button
   - Opens creator with platform, content type, content idea
   - Campaign context is included for better prompts

This interconnectivity means:
- Users never start from scratch
- Context flows automatically between features
- AI generates better content with more context

================================================================================
                            TECHNICAL ARCHITECTURE
================================================================================

FRONTEND (Next.js 16 + React 19)
├── App Router for navigation
├── Server-side rendering for performance
├── Tailwind CSS v4 for styling
├── Axios for API communication
└── Recharts for data visualization

BACKEND (FastAPI + Python)
├── RESTful API endpoints
├── SQLAlchemy ORM with SQLite database
├── Google Gemini 2.5 Flash for AI
├── Pollinations.ai for image generation
└── Instaloader for Instagram scraping

DATA FLOW:
1. User interacts with Next.js frontend
2. Frontend calls FastAPI backend via Axios
3. Backend queries database or calls AI APIs
4. AI (Gemini) processes and returns results
5. Backend sends response to frontend
6. Frontend displays results with animations
